# Weight me up

Εφαρμογή για απώλεια λίπους και γράμμωση, στα ελληνικά. Καταγράφεις φαγητό, βάρος, ύπνο και προπόνηση, και παίρνεις εβδομαδιαίο πλάνο γευμάτων και έτοιμο πρόγραμμα γυμναστηρίου. Δουλεύει στο κινητό σαν κανονική εφαρμογή (PWA), και offline.

**Όλα τα δεδομένα μένουν στη συσκευή του χρήστη.** Δεν υπάρχει server, λογαριασμός ή analytics. Η μόνη σύνδεση στο διαδίκτυο είναι η αναζήτηση barcode στο Open Food Facts.

## Τι κάνει

| Καρτέλα | Τι έχει |
| --- | --- |
| Ημέρα | Καταγραφή γευμάτων (αναζήτηση στα ελληνικά ή greeklish, barcode, ελεύθερο κείμενο), άσκηση με χρονόμετρο διαλείμματος, βήματα, ύπνος, ζύγιση |
| Εβδομάδα | Θερμίδες ανά ημέρα, ενεργειακό ισοζύγιο, γραφήματα βάρους |
| Πλάνο | Διαλέγεις τα φαγητά που τρως και φτιάχνεται εβδομάδα 7 ημερών στους στόχους σου. Καταγραφή γεύματος με ένα πάτημα. Έτοιμο ολόσωμο πρόγραμμα A/B/C (3 ημέρες) και οδηγός για ύπνο, συνήθειες και συμπληρώματα |
| Πρόοδος | Τάση βάρους, μετρήσεις σώματος, φωτογραφίες προόδου, όγκος προπόνησης ανά μυϊκή ομάδα, τάση δύναμης |
| Προφίλ | Στόχοι θερμίδων και μακροθρεπτικών, προγράμματα προπόνησης, βάση τροφίμων (≈255 ελληνικά τρόφιμα και πιάτα), συνταγές, αντίγραφα ασφαλείας με κρυπτογράφηση |

## Δημοσίευση στο GitHub Pages

1. Φτιάξε νέο **public** repository στο GitHub (π.χ. `weight-me-up`).
2. Ανέβασε όλα τα αρχεία αυτού του φακέλου στη ρίζα του repository.
3. **Settings → Pages → Build and deployment → Source: Deploy from a branch**, branch `main`, φάκελος `/ (root)`, **Save**.
4. Σε 1–2 λεπτά η εφαρμογή είναι στο `https://<username>.github.io/<repository>/`.

Στο κινητό: άνοιξε τη διεύθυνση και πάτα «Προσθήκη στην αρχική οθόνη» (iPhone: Safari → Κοινοποίηση → Προσθήκη στο Home Screen).

## Αλλαγές στον κώδικα

Μετά από κάθε αλλαγή, πριν το commit:

```bash
python3 tools/build.py
```

Ξαναϋπολογίζει τα hashes των inline scripts στο Content-Security-Policy (αλλιώς ο browser μπλοκάρει τα scripts και η σελίδα μένει λευκή) και δίνει νέα έκδοση στο `sw.js`, ώστε οι χρήστες να πάρουν την ενημέρωση.

| Αρχείο | Ρόλος |
| --- | --- |
| `index.html` | Η εφαρμογή: έλεγχοι δεδομένων, υπολογισμοί στόχων, αποθήκευση (IndexedDB με εφεδρικό localStorage), οθόνες |
| `plan.js` | Καρτέλα «Πλάνο», επιπλέον ελληνικά τρόφιμα, φυτικές ίνες για τα ενσωματωμένα τρόφιμα |
| `ui.css` | Διάταξη για κινητό: πρώτα η κάρτα θερμίδων, σταθερές καρτέλες, μεγαλύτερα κουμπιά, παράθυρα από κάτω |
| `ui.js` | Σάρωση αριστερά/δεξιά για αλλαγή ημέρας, σύρσιμο προς τα κάτω για κλείσιμο παραθύρου |
| `sw.js` | Service worker για offline λειτουργία |
| `zxing.min.js` | Ανάγνωση barcode από την κάμερα |
| `tools/build.py` | CSP hashes και έκδοση service worker |

## Σημείωση

Η εφαρμογή δίνει γενικές πληροφορίες και δεν αντικαθιστά γιατρό ή διαιτολόγο. Αν παίρνεις φάρμακα, ρώτα γιατρό ή φαρμακοποιό πριν από συμπληρώματα.

---

**English:** Greek-language PWA for fat loss: food, weight, sleep and training logs, a 7-day meal planner built from the foods you actually eat, a 3-day full-body program, and habit guides. Everything is stored locally on the device. Deploy by pushing this folder to a GitHub repository and enabling GitHub Pages from the `main` branch root. Run `python3 tools/build.py` after any change.
